# IOT-project
Smart Traffic

The **Smart Traffic Management System** is an IoT-based project developed using an **ESP32 microcontroller** to create an automated and responsive traffic control system. The main goal of the project is to improve traffic flow by monitoring real-time movement and automatically controlling traffic signals based on sensor input.

The system integrates **IR/PIR sensors** to detect vehicle movement or traffic activity and uses this information to control **red, yellow, and green LEDs** representing traffic lights. A **servo motor** is also used to simulate an automated traffic gate, while a **16×2 I2C LCD** displays the current traffic or system status. A **buzzer** provides an additional alert when specific conditions are detected.

The project demonstrates the practical use of **IoT, embedded systems, sensors, and automation** to solve a real-world transportation problem. By reducing the need for manual traffic control and responding to changing traffic conditions in real time, the system provides a foundation for developing more advanced **smart city and intelligent transportation solutions**.
